Vyremaid links each member's Discord account to their in-game RSN and keeps a clan role in sync automatically via Wise Old Man group membership — no manual role management. From there it covers the everyday utility stuff a clan actually needs: live hiscores and skill lookups, boss kill counts, a money-making guide filtered to what you personally qualify for, Grand Exchange prices and loot-split calculations, Skill/Boss of the Week tracking, clan-wide XP leaderboards, live trackers for shooting stars and Tears of Guthix worlds, and recurring reminders/announcements.

Setting up the bot

The two things worth getting right on day one: inviting it with the right permissions, and deciding which channels it's allowed to talk in.

1. Invite & permissions

  1. Click Invite Vyremaid at the top of this page and pick your server.
  2. The invite link already requests everything it needs: Send Messages, Embed Links, Read Message History, View Channel, and Manage Roles. Don't untick any of these — features silently stop working without them.
  3. In Server Settings → Roles, drag the bot's own role above any role you want it to manage (e.g. your clan role). Discord blocks bots from assigning or removing roles ranked above their own — this is the #1 reason role sync doesn't work after setup.

2. Choose which channels it can be used in

By default every command works in every channel — fine for a small server, noisy for a bigger one. If you want to keep it contained:

  1. Pick a channel (e.g. #bot-commands) and run !addbotchannel #bot-commands there. This is opt-in — the moment you approve one channel, everyday commands stop working everywhere else.
  2. Run it again for any other channel you want approved (e.g. a general chat where hiscores lookups are welcome) — !addbotchannel can be used as many times as you like, it's additive, not a single slot.
  3. Check what's currently approved anytime with !listbotchannels, and remove one with !removebotchannel #channel.
  4. If someone runs a restricted command in the wrong channel, the bot deletes their message and posts a short-lived reminder pointing at the right channel — no manual moderation needed.
  5. /setusername is the one exception: the slash version always works from any channel and replies privately, so new members can link their account without hunting for the right place first.

3. Connect it to your clan

  1. Run !setgroup <your Wise Old Man group link> — powers !sotw auto-detection, !top, !avg, and role sync.
  2. Run !setclanrole @YourRole to pick which role gets auto-assigned/removed based on WOM group membership.
  3. Have members run !setusername <their RSN> — this saves their account and immediately checks/applies the clan role. An admin can run !setuser @member <rsn> on someone's behalf if they haven't done it themselves.
  4. Optionally run !syncroles once to backfill roles for anyone who linked before setup finished.

That's everything — role sync re-checks every 30 minutes automatically from here. Full command-by-command reference (including reminders, WOM auto-refresh, and every admin command) is in the command reference PDF.
