Gear catalog (!ge / !gear / !equip)

Every buyable item, split by combat style. Weapon and ring are the only slots that reduce task time (Speed); every other slot carries a Defense rating instead, which reduces how much food a Medium/Hard slayer task burns through (see Formulas). Buying via !ge is never level-gated — only !equip checks the level requirement.

Gathering resources (!gather)

Woodcutting, Mining, Fishing, and Flax (Crafting) — open-ended, runs until you !stopgather. !gather fuzzy-matches past filler words ("ore", "rock", "spot"), so !gather copper and !gather copper ore both work.

Processing recipes (!use)

Cooking, Crafting, Prayer, Fletching, and Smithing — all queued through !use, flat 2s/unit regardless of tier (unlike gathering, which gets slower at higher tiers). Recipes with more than one possible output prompt you to pick one via reaction when you start it.

Firemaking (!burn)

Its own command since Firemaking and Fletching both want to consume the same log items — burning always grants Firemaking xp only, no item produced.

Bow stringing (!string)

Finishes an unstrung bow (from Fletching's log recipes) using 1 Bow string per bow (Bow string comes from !use Flax). Roughly doubles the bow's sell value over leaving it unstrung.

Monsters & drop tables (!slaytask)

Easy tasks never need food. Medium/Hard burn cooked food per kill (reduced by your Defense rating, never eliminated) — see Formulas for the exact rates. Drop chance is per-kill, independent of the guaranteed bones drop.

Food (!ge / cooking)
