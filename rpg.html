A small idle RPG built into the bot, on top of an OSRS skin — get a slayer task, let it run in the background while you do literally anything else (including actually playing OSRS), come back to loot and levels. Everything below runs entirely inside Discord — !slaytask to start, one active task at a time, completion posts automatically wherever you started it.

How the loop works

Two task types share one system — you can only have one running at a time, of either kind.

Idle by design. Task times are deliberately slow (minutes, not seconds) — this is meant to run in the background while you're doing something else, not something you sit and watch. A completion embed posts automatically when it's done, with a ✅/❌ reaction to instantly queue the same thing again.

Slayer tasks — combat

!slaytask assigns a monster and a kill count (8–15) based on your current Slayer level. It resolves as one batch when the timer's up — all the kills, loot, and XP land at once.

!use — processing skills

!use <item> [qty|all] queues Cooking, Crafting, Prayer, Fletching, or Smithing as a timed batch (~2s/unit) — the same idle pattern, just for turning loot into something useful instead of fighting. One command covers all five skills, since the natural verbs (!cook, !craft) already collide with the bot's real-account hiscores lookups.

!burn — Firemaking

!burn <logs> [qty|all] is the same queued-batch idea, kept as its own command because Firemaking and Fletching both want to consume the same log items and !use only supports one recipe per item. Burning always just grants Firemaking xp — no item produced.

Combat styles & equipment

!style <melee|mage|ranged> sets which skills your tasks train and which gear applies. (Not !melee/!mage/!range as separate commands — those collide with the bot's real-account skill lookups.)

10 equipment slots

Weapon, shield, head, body, legs, hands, feet are style-locked (only usable with the matching !style). Cape, amulet, and ring are universal — equip once, they apply no matter which style is active.

Speed vs. defense. Only the weapon and ring slots reduce task time (up to 30% and 4%). Every other slot carries a defense rating instead — currently inert, reserved for a planned food-consumption / death-chance system on harder content. Real OSRS precedent: a Berserker ring boosts damage, a Rune helm is purely defensive.

Level speed bonus

Your average level across a style's trained skills also reduces task time — 0.3% per level, so level 99 is 29.7%, not 99%. Combined gear + level speed is capped at a 30% floor (max ~70% reduction) so nothing approaches an instant kill.

Gathering skills

Woodcutting, Mining, and Fishing — started with !gather <resource>, stopped with !stopgather. Unlike Slayer or !use, gathering has no fixed duration: it just runs until you stop it, so it's the one meant for genuinely long AFK stretches (overnight etc) rather than the several-minute-to-an-hour scale everything else runs at. XP and items are paid out based on real elapsed time when you stop.

!gather fuzzy-matches the resource name — filler words like "ore", "rock", and "spot" are ignored, so !gather Copper and !gather Copper ore both start the same node.

Economy

A self-contained in-game currency, not tied to real GE prices.

Buying & selling

!ge <item>Shows price, confirm with ✅/❌, deducts gp and adds it to your inventory. Check !gear first for what's available.
!equip <item>Equips an owned item into the right slot automatically.
!gesell <item> [qty|all]Sells at half a weapon/armor's buy price, or a fixed rate for loot. Every item is sellable, even free starter gear (minimum 1gp).

Processed goods sell for more

Cooking/Crafting a raw drop into something else multiplies its sell value 7x — a real incentive to process loot instead of just selling it raw, and a fast way to build starting capital.

Tutorial nudge

The first time your Attack hits level 5, you're handed exactly enough gp for a Steel scimitar (500gp), with a prompt to buy and equip it — walks a new player through !ge/!equip once, using their own progress as the trigger instead of a wall of setup text.

Slayer points

+1 per completed slayer task, shown in !char. A points shop is planned but not built yet.

Setting it up

One extra step beyond the main bot setup — the RPG has its own channel allowlist, separate from everyday commands, so task spam doesn't flood existing channels.

1. Approve a channel (admin, optional but recommended)

  1. Pick a channel (e.g. #rpg) and run !addrpgchannel #rpg there. This is opt-in — until you approve one, RPG commands work anywhere.
  2. Run it again for any other channel you want approved — additive, not a single slot.
  3. Check what's approved with !listrpgchannels, remove one with !removerpgchannel #channel.

2. Start playing

  1. Run !slaytask to get your first task — starts at the tutorial tier automatically.
  2. Let it run in the background. Completion posts automatically with a ✅ reaction to queue the next one.
  3. Process loot with !use, sell what you don't need with !gesell, gear up with !ge + !equip.
  4. Switch combat style anytime with !style — melee, mage, or ranged.

This is a first pass — a slayer-points shop, more monster tiers, and further skills are still planned. Check the RPG Wiki for the full, exact item/recipe/monster catalog, or the overview page for everything else the bot does.
